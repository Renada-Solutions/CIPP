# Checklist

This page lists AI controls that cannot be set through an API, for the selected tenant: what to set, where to set it, who confirmed it was done and when. A confirmation is due for review after 90 days. Items required by an applied AI Access Policy are listed first and count towards the policy's compliance.

## Table Details

| Column | Description |
| --- | --- |
| Status | Not confirmed, Confirmed, or Review due. |
| Required | Whether an applied AI Access Policy requires this control. |
| Area, Title | The control. |
| Where | Where to set it. |
| Confirmed By, Confirmed At, Review By | The confirmation record. |
| Required By | The policies that require it. |
